Smart Class Fee Manager 2.0 – Android Project

இந்த project-ல்:
- மாணவர் பதிவு + Student ID
- QR Class Card (உண்மையான QR)
- QR Camera Scan
- மாதாந்த கட்டணம் + நிலுவை
- Payment History
- Present / Absent தேதி வாரியாக
- Attendance Summary / Report
- Dashboard Summary
- Backup / Restore

முக்கியம்:
இது Android Studio/Gradle மூலம் APK உருவாக்கக்கூடிய project ZIP.
இந்த சூழலில் Android SDK/Gradle build tools இல்லாததால் APK-ஐ இங்கே compile செய்து verify செய்ய முடியவில்லை.

Android Studio-ல்:
1. ZIP-ஐ Extract செய்யவும்.
2. Android Studio → Open → SmartClassFeeManager_Android_App_Project folder.
3. Gradle Sync முடிந்ததும் Build → Build APK(s) தேர்வு செய்யவும்.
4. உருவாகும் APK-ஐ Android phone-ல் install செய்யலாம்.

Camera:
AndroidManifest-ல் CAMERA permission உள்ளது. WebView camera permission handling MainActivity-ல் உள்ளது.
